# Resumo do Projeto

O **Verdade ou Bug** (Tech Trivia) é um quiz de afirmações de verdadeiro ou falso voltado a estudantes e entusiastas da área de Tecnologia e Inovação. O objetivo principal deste banco de dados relacional é armazenar e disponibilizar de forma estruturada e normalizada o acervo de perguntas, suas categorias, respostas, explicações, níveis de dificuldade, pontos e fontes bibliográficas de referência. Além de prover os dados para o sorteio de questões na aplicação web, o projeto engloba uma extensão opcional para registrar o nome e ícone de perfil do usuário, o histórico de partidas e a pontuação para a exibição do ranking.
