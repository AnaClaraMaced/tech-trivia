# 🎮 Verdade ou Bug  — Tech Trivia

> **Aplicação Web Interativa de Quiz / Trivia sobre Tecnologia**  
> Projeto Interdisciplinar dos cursos de Tecnologia (Design Profissional, Desenvolvimento Front End, Pensamento Computacional e Modelagem de Banco de Dados).

---

## 📌 Sobre o Projeto

O **Verdade ou Bug (Tech Trivia)** é uma aplicação web do tipo *trivia/quiz* que apresenta fatos, curiosidades e conceitos do universo tecnológico. O objetivo principal é proporcionar uma experiência lúdica e educativa, testando o conhecimento dos usuários e oferecendo explicações detalhadas acompanhadas de fontes de referência.

Este projeto integra de forma prática e transversal quatro disciplinas:

* **Design Profissional:** Pesquisa, validação dos conteúdos/perguntas e prototipagem da interface.
* **Desenvolvimento Front End para Web:** Criação da interface web dinâmica, estilização acessível e interatividade.
* **Pensamento Computacional:** Lógica de jogo, cálculo de pontuação, controle de fluxo e algoritmo de ranking.
* **Modelagem de Banco de Dados:** Estruturação e modelagem do banco relacional PostgreSQL.

---

## 🚀 Tecnologias Utilizadas

### **Front-End & Documentação**
* **HTML5** (Estruturação semântica e acessível)
* **CSS3** (Variáveis CSS, Flexbox, layouts responsivos e suporte a Tema Claro/Escuro)
* **JavaScript (ES6+)** (Manipulação de DOM, cronômetro, modais e gerenciamento do estado da partida)
* *Desenvolvido com JS, HTML e CSS puros (Vanilla), sem frameworks ou bibliotecas externas.*

### **Back-End & Banco de Dados**
* **Render** (Hospedagem e deploy do servidor/API backend)
* **Supabase / PostgreSQL** (Modelagem, persistência de dados e gerenciamento do ranking em nuvem)

---

## ✨ Funcionalidades Principais

- [x] **Cadastro e Personalização:** Escolha de nome do jogador e avatar personalizado em emoji.
- [x] **Fluxo de Perguntas Flexível:** Exibição de uma questão por vez, permitindo alterar a alternativa selecionada antes da confirmação.
- [x] **Feedback Educacional e Fonte:** Explicação detalhada após a confirmação da resposta, com link direto para a fonte original.
- [x] **Painel de Resultados e Estatísticas:** Apresentação da pontuação final (100 pts por acerto), tempo total e maior sequência de acertos.
- [x] **Análise Interativa de Respostas:** Modal interativo para rever cada pergunta e sua respectiva explicação.
- [ ] **Ranking Global e Persistência:** Integração com banco de dados via Supabase para salvar e listar as maiores pontuações *(Em andamento)*.
- [x] **Tema Claro / Escuro:** Alternância de tema com contraste calibrado para acessibilidade.
- [ ] **Acessibilidade & Responsividade:** Navegação por teclado, suporte a leitores de tela e layout adaptável a telas móveis.

> ⚠️ **Nota de Status:** O projeto encontra-se em desenvolvimento ativo. Novas integrações entre a interface e o servidor backend (Render + Supabase) estão sendo finalizadas.

## 🛠️ Como Executar o Projeto

### Pré-requisitos
Navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge ou Safari).

### Execução Local
1. Clone este repositório:
   `git clone https://github.com/AnaClaraMaced/tech-trivia.git`

2. Acesse a pasta do projeto:
   `cd tech-trivia`

3. Abra o arquivo `index.html` diretamente em seu navegador.
